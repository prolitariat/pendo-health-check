--- EXTENSION NAME ---
Pendo Health Check

--- SHORT DESCRIPTION (132 chars max) ---
Side project, not an official Pendo product. Six Quick Copy chips, A to F install grade, score diff, CMP consent-gating check.

--- DETAILED DESCRIPTION ---
Heads up: this is a side project built by a Pendo customer admin, not by Pendo. Not affiliated with or endorsed by Pendo. No SLA, no support contract, no guarantees. If something breaks, file a GitHub issue; please don't open a Pendo support ticket, because Pendo didn't ship this and can't help with it.

Open it on any page with Pendo and get two things at once: a Quick Copy chip grid for the values you reach for most, and a letter grade (A to F) for the install. Built so Pendo admins, implementation engineers, and support folks can make decisions faster with less effort.

QUICK COPY CHIPS

Six chips, one-click copy. The values an operator actually pastes into a ticket, Slack, or API call:

• Visitor ID
• Account ID
• Subscription ID
• Session ID
• Agent Version
• Realm (US / EU / US1 / JP / Custom CNAME)

Empty values render grayed out and uncopyable so you can tell at a glance what's actually set vs. missing. Diagnostic state (framework, ready/not-ready, active guides count) intentionally stays out of the chip grid because it isn't a copy-paste value; it's covered by the grade pill and the "Why this grade" drawer.

INSTALLATION GRADE (A to F)

A compact pill in the header shows the current grade. A score-diff badge next to it shows the delta from your previous visit to the same page (history keyed by hostname + path, last five entries persisted locally). Click the badge to see recent grades for that page.

WHY THIS GRADE (drawer)

Open the "Why this grade" drawer to see the full prioritized findings list, sorted by severity. The drawer stays collapsed by default so the default view stays focused on the chips.

Health checks:
• Agent loaded, initialized, version
• Visitor and Account ID validation (flags anonymous, missing, malformed)
• Duplicate detection (multiple instances or agent scripts)
• Data Transmission (catches ad blocker, CSP, firewall blocks)
• Feature Flags (surfaces disabled features like guides off, analytics off)

Setup analysis:
• Framework detection (React, Angular, Vue, Ember, Svelte, Next.js, Nuxt, jQuery)
• Snippet analysis (install method, placement, async loading)
• CSP compatibility directive by directive, with strict-dynamic and nonce awareness; Report-Only CSP detected and not flagged as blocking
• CNAME-aware host detection for custom CDN and data endpoints
• Visitor and account metadata validation (PII detection, data types, field naming)

CMP CONSENT-GATING CHECK

If a consent manager is on the page and Pendo is initialized with a non-anonymous visitor while the CMP reports analytics consent denied, the extension flags it with a warning and links to that CMP's remediation docs. Actionable detection on Cookiebot, Didomi, Osano, and a narrow OneTrust read. Inform-only on TrustArc and TCF v2.0. The check is intentionally conservative: any unknown signal suppresses the flag, so anonymous-pre-consent and strictly-necessary classifications never get falsely flagged.

COPY ISSUES TO CLIPBOARD

One click, one plain-text output. Behind the scenes the extension runs Pendo's own pendo.validateInstall(), captures its console output, and appends it to the report under a labeled section. The artifact you hand to engineering contains both the extension's interpretation AND Pendo's own verdict in one paste. The preamble identifies the tool, version, and source repo and notes that doc URLs at the bottom are verified Pendo Help Center articles. That orientation is enough for both a human reader (Slack, Jira, a support ticket) and an LLM (Claude or ChatGPT triage). No format selector to fiddle with.

TOGGLE PENDO DEBUGGER

Pinned top-level button next to Copy Issues. One click opens or closes Pendo's on-page debug overlay. The debugger is the daily tool for tagging operators, in-app content authors, and Pendo support staff, so it sits outside any "developer tools" framing.

ICON BADGE

Yellow shows issue count after analysis; red shows critical problems. Clears when you change pages so it never shows stale data. Toggle from the footer.

PENDO SERVICE STATUS

Live from status.pendo.io, surfaced only during incidents. Included in the copied report.

PRIVACY

All checks run locally in your browser. Score history is stored in chrome.storage.local on your device only. Nothing leaves the extension. No account, no login.

SOURCE

Source code, issue tracker, and changelog at github.com/prolitariat/pendo-health-check.
