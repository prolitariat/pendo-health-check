--- EXTENSION NAME ---
Pendo Health Check

--- SHORT DESCRIPTION (132 chars max) ---
Side project, not an official Pendo product. Grades any Pendo install A to F with prioritized diagnostics and inline tools.

--- DETAILED DESCRIPTION ---
Heads up: this is a side project built by a Pendo customer admin, not by Pendo. Not affiliated with or endorsed by Pendo. No SLA, no support contract, no guarantees. If something breaks, file a GitHub issue; please don't open a Pendo support ticket, because Pendo didn't ship this and can't help with it.

Open it on any page with Pendo and you get a letter grade (A to F) plus a single prioritized list of what's wrong. No DevTools required.

Built for Pendo admins and implementation engineers who need to hand a specific list of problems to engineering.

INSTALLATION GRADE (A to F)

Your install is scored across runtime health checks and a setup analysis. Issues sort by severity, so the worst things sit at the top.

Health checks:
• Agent loaded (pendo.js is on the page)
• Initialization (pendo.isReady() returns true)
• Visitor ID (flags anonymous IDs)
• Account ID
• Active Guides (count and state)
• Duplicate detection (multiple instances or agent scripts)
• Agent Version
• Data Transmission (analytics data is reaching Pendo servers)
• Feature Flags (surfaces disabled features like guides off, analytics off)

Setup analysis, merged into the same view:
• Framework detection (React, Angular, Vue, Ember, Svelte, Next.js, Nuxt, jQuery)
• Snippet analysis (install method, placement, async loading)
• CSP compatibility, directive by directive, with strict-dynamic and nonce awareness
• Report-Only CSP detection, so non-enforcing policies aren't flagged as blocking
• CNAME-aware host detection for custom CDN and data endpoints
• CMP and GDPR consent detection (OneTrust, Cookiebot, Didomi, Osano, TrustArc, TCF v2.0)
• Visitor and account metadata validation (PII detection, data types, field naming)
• Recommendations with links to Pendo docs

COPY TO CLIPBOARD

One click exports a priority-sorted diagnostic report with remediation steps. Paste into Slack, Jira, or a support ticket. Includes grade, issues, and service status.

DEVELOPER TOOLS

• Toggle Pendo Debugger, one click, no DevTools needed
• Validate Install, runs pendo.validateInstall() inline
• Validate Environment, runs pendo.validateEnvironment() inline

ICON BADGE

Yellow shows issue count after analysis; red shows critical problems. The badge clears when you change pages so it never shows stale data. You can toggle it off from the footer.

PENDO SERVICE STATUS

Live from status.pendo.io, surfaced only during incidents. Included in the copied report.

PRIVACY

All checks run locally in your browser. Nothing leaves the extension. No account, no login.

SOURCE

Source code, issue tracker, and changelog at github.com/prolitariat/pendo-health-check.
