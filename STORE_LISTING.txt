--- EXTENSION NAME (FROM PACKAGE) ---
Pendo Health Check

--- SHORT DESCRIPTION (FROM PACKAGE, 132 CHARACTERS MAXIMUM) ---
Side project, not an official Pendo product. Compact dashboard, A-F install grade, Quick Copy IDs, optional auto-check badge.

--- DETAILED DESCRIPTION ---
Inspect a page's Pendo installation, copy the IDs you need, and open Pendo's debugger from one compact popup.

Pendo Health Check is an independent side project built by a Pendo user. It is not an official Pendo product and is not affiliated with or endorsed by Pendo. Please report extension problems through the GitHub issue tracker rather than Pendo support.

STATUS: COMMON ACTIONS UP FRONT
See an A-to-F installation grade and review findings from the extension's health and setup checks. Copy available Visitor and Account IDs, toggle Pendo's on-page debugger, and use Copy Issues to Clipboard when actionable warnings or errors exist. Open Why this grade? for explanations, suggested fixes, and documentation links.

IDS: ONLY AVAILABLE VALUES
Copy populated Visitor, Account, Subscription, Session, Agent, and Realm values. Empty rows are hidden. Copy all as JSON exports the full set of identifier fields, including null values.

TOOLS: OPTIONAL AUTOMATIC CHECKS
Choose whether to show the issue-count badge. Auto-check pages on load is off by default. Turning it on requests optional access to websites so a smaller background check can update the badge after page loads. Opening the popup runs the fuller analysis.

WHAT IT CHECKS
Agent presence and readiness, identity, duplicate agent scripts, available configuration and metadata, hosting and network signals, snippet setup, CSP, framework clues, and supported consent-manager signals.

The grade uses this extension's rules. Network signals do not prove server-side event delivery, and consent findings are prompts for implementation review. When you click Copy Issues, the extension also runs pendo.validateInstall() if available and adds captured console output to the report.

PRIVACY AND SHARING
Diagnostic analysis runs in your browser. The extension sends usage events to the publisher's Cloudflare Worker, including event names, extension version, and basic action context or check counts. Those usage-event payloads exclude inspected URLs, visitor/account ID values, page contents, cookies, and authentication tokens. Version 4.6.1 has no analytics opt-out setting.

Copied reports can contain the inspected URL, diagnostic details, and Pendo validation output. Review them before sharing. Send feedback opens a GitHub issue draft with technical context; it does not submit an issue automatically. The extension also requests Pendo's public service-status summary for copied-report context.
